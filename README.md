# ЛУЧ v1.5

Голосовой ассистент для Linux. К базовой версии добавились облачный провайдер
моделей (OpenCode Zen), красивый консольный вывод на `rich` и GUI-пульт
управления на PySide6.

## Что умеет

| Возможность | Реализация |
|---|---|
| Распознавание речи | faster-whisper (локально) или Google через `speech_recognition` |
| Синтез речи | Silero TTS, русские голоса |
| Голосовой пропуск | speechbrain (ECAPA): ассистент реагирует только на ваш тембр |
| Локальные модели | Ollama |
| Облачные модели | OpenCode Zen — свой API-ключ и выбор модели |
| Слово-триггер | обращение по заданному слову |
| Управление ПК | `terminal`, `lock_pc`, `print_text`, `web_search` |
| Таймеры | будильник и таймер с голосовым оповещением |
| GUI-пульт | PySide6: запуск, мониторинг, настройки |
| Веб-интерфейс | FastAPI-сервер |

## Отличия от v1

- **Облачные модели.** Появился провайдер OpenCode Zen: команды `/provider`,
  `/zen_api`, `/zen_model`. Можно выбирать между локальной Ollama и облаком.
- **GUI-пульт.** `gui_launcher.py` — окно на PySide6: запускает и останавливает
  ядро, показывает статус, температуру, загрузку, позволяет менять настройки
  и открывать чат.
- **Консольный вывод через `rich`.** Рамки, панели, подсветка вместо голого текста.
- **Таймеры и оповещения.** `/api/alerts` и `/api/alert_audio` в веб-сервере.

## Установка

Нужен Python 3.11+ и запущенный [Ollama](https://ollama.com).

```bash
python -m venv venv && source venv/bin/activate

pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu130

pip install faster-whisper SpeechRecognition speechbrain silero-tts \
            ollama fastapi uvicorn pygame-ce numpy scipy \
            python_speech_features requests colorama art rich PySide6
```

## Запуск

```bash
python main.py          # ядро + веб-интерфейс
python gui_launcher.py  # графический пульт (сам запускает ядро)
```

Веб-интерфейс: `http://<ip>:1337`

## Настройки

`settings.json` создаётся автоматически. Кроме настроек v1 добавлены:

| Ключ | Назначение |
|---|---|
| `provider` | `ollama` или `zen` |
| `zen_api_key` | ключ OpenCode Zen |
| `zen_model` | облачная модель |

## Важно про безопасность

**У веб-API нет аутентификации** — любой в вашей сети может отправить запрос и
выполнить команду на компьютере. Не выставляйте порт 1337 в интернет.
Обязательная аутентификация по токену появилась только в версии 1.8.

## Чем отличается от следующих версий

Здесь ещё нет полноценного веб-интерфейса (`static/app.js`), навигации и
геолокации, управления телефоном и Android-приложения — они появились в
v1.6 и v1.7.
